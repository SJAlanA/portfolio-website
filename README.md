# S J Alan Anbu Kulandainathan — Portfolio

A one-page portfolio. As you scroll, a short checklist in the margin is crossed off, one item per chapter.

**Live:** https://sjalana.github.io/portfolio-website/

## Run it

```bash
npm install
npm run dev
```

Built with plain HTML, CSS and JS on [Vite](https://vite.dev). Pushes to `new-portfolio` deploy to GitHub Pages.
